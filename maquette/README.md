# Maquette de l'application Civipédia Conseil

Copie de la maquette du dépôt `civipedia-conseil` (dossier `maquette/`). Ce dépôt étant publié en ligne, la maquette est consultable à l'adresse `analscopie.github.io/civipedia-territoires/maquette/maquette-application.html`.

Maquette mobile (390 × 844) de l'application membre. Les noms, dates et organismes sont des exemples (`[Prénom]`, `[Personne A]`, `[jj/mm/aaaa]`…).

| Fichier | Contenu |
|---|---|
| `maquette-application.html` | Maquette interactive en un seul écran, à ouvrir dans un navigateur (JavaScript nécessaire, fonctionne hors ligne) |
| `maquette-application.pdf` | Les mêmes écrans en PDF |
| `ecran-accueil.png` | Capture de l'écran d'accueil |

## Écrans

1. **Accueil** : déposer un PDF, coller un lien ou poser une question ; dossiers en cours.
2. **Lecture de l'appel d'offres** : client, date limite, budget, demande, compétences nécessaires (disponible / à vérifier / manquante).
3. **Équipe proposée (RACI)** : Réalise, Valide, Conseille, Informé ; rien n'est engagé avant validation.
4. **Question à la base** : pistes trouvées dans la base Coopération, à confirmer avec chaque personne.
5. **Dossiers** (barre du bas) : les dossiers suivis ; le signal de veille ouvre sa propre fiche, « à qualifier ».

Tous les écrans sont reliés dans une seule application. La barre du bas mène à Accueil, Dossiers et Réseau (question à la base). Les fonctions pas encore conçues (profil, « Moi », « Modifier », dictée) affichent « Bientôt disponible ».
