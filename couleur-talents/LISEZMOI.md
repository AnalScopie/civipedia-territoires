# Couleur Talents — Mes outils

Page d'accueil installable (PWA) qui regroupe les outils de Couleur Talents en 3 gros boutons, pour Corine : le questionnaire, les dossiers Drive Couleur Talents (avec des raccourcis vers chaque sous-dossier) et l'outil Équipe et missions. Page en construction, en attendant le tableau de bord complet.

Adresse : `https://analscopie.github.io/civipedia-territoires/couleur-talents/`

| Bouton | Lien |
|---|---|
| Le questionnaire d'orientation | `../profil-professionnel/` |
| Les dossiers Couleur Talents | Dossier Drive « Couleur Talents » |
| L'équipe et les missions | Page Claude « Équipe et missions » |
| Accès Corine | `corine.html` : fiches, répertoire, scores de l'équipe, documents à analyser, références |

Pour changer un bouton : modifier la liste `OUTILS` en haut du script de `index.html`.

**Attention :** l'adresse de cette page n'est donnée qu'à Corine, mais la page elle-même n'est pas protégée. Les dossiers Drive ouverts à « toute personne disposant du lien » sont donc lisibles par quiconque trouve la page. Pour les protéger, passer leur accès général sur « Limité » et les partager nommément.

## Installer sur un téléphone

- **Android / Chrome :** ouvrir la page, appuyer sur « Installer l'application ».
- **iPhone / Safari :** bouton Partager, puis « Sur l'écran d'accueil », puis « Ajouter ».

## Intégrer le questionnaire au site couleur-talents.fr

Consignes pour la personne qui gère le site, avec le code à copier : `couleur-talents/integration.html` (adresse : `https://analscopie.github.io/civipedia-territoires/couleur-talents/integration.html`).
