Pour la personne qui gère le site couleur-talents.fr

Ajouter le questionnaire d'orientation au site

Le questionnaire s'affiche dans une page du site, comme s'il en faisait partie. Il faut seulement coller un petit code. Comptez 5 minutes.

1. Copier le code

<iframe id="ct-profil" src="https://analscopie.github.io/civipedia-territoires/profil-professionnel/"
  style="width:100%;border:0;min-height:900px" title="Questionnaire d'orientation Couleur Talents"
  allow="clipboard-write"></iframe>
<script>
addEventListener("message", function (e) {
  if (e.origin === "https://analscopie.github.io" && e.data && e.data.type === "ct-profil-height")
    document.getElementById("ct-profil").style.height = e.data.height + "px";
});
</script>

2. Le coller dans WordPress

  1. Dans WordPress, créer une nouvelle page (ou ouvrir la page choisie), par exemple « Questionnaire d'orientation ».
  2. Cliquer sur + pour ajouter un bloc, chercher HTML personnalisé.
  3. Coller le code dans ce bloc.
  4. Cliquer sur Aperçu pour vérifier, puis sur Publier.

3. Vérifier

  1. Ouvrir la page publiée, sur ordinateur et sur téléphone.
  2. Le questionnaire doit s'afficher en entier, sans deuxième barre de défilement : la hauteur s'ajuste toute seule.
  3. Répondre à 2 ou 3 questions, fermer la page, la rouvrir : « Reprendre où j'en étais » doit apparaître.
Bon à savoir. Le questionnaire ne demande ni nom ni adresse, et n'envoie aucune réponse au site ni à Couleur Talents : tout reste dans le navigateur de la personne. Il n'y a donc rien à ajouter à la politique de confidentialité pour la collecte de données. Si le site utilise une extension de sécurité qui bloque les « iframes », autoriser l'adresse analscopie.github.io.
