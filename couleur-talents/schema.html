La liste de l'équipe (base Civipédia)

Les compétences de chacun viennent de la base commune Civipédia, tenue à jour par Anne. Elle nourrit « L'équipe et les missions ».

Le principe

  • On range tout une seule fois, dans le Drive Couleur Talents.
  • Les outils lisent le Drive : rien n'est recopié ailleurs.
  • Le questionnaire garde les réponses sur l'appareil de la personne ; seuls les scores partagés volontairement arrivent dans le Drive.
  • Corine a sa porte d'entrée : l'Accès Corine.

Ce qui arrive ensuite

  • Le tableau de bord de Corine, avec mot de passe.
  • Relier chaque famille de métiers à une offre Couleur Talents.
  • Mettre le questionnaire sur le site couleur-talents.fr.
