Civipédia Installer le guichet des fiches de contact

À faire une seule fois. Le guichet reçoit les fiches remplies sur la page Fiche de contact et les range dans le tableur privé FICHES_CONTACT_CIVIPEDIA.

  1. Appuyez sur le bouton noir ci-dessous : le texte est copié.
  2. Ouvrez le tableur FICHES_CONTACT_CIVIPEDIA, puis le menu Extensions → Apps Script.
  3. Dans le fichier Code.gs, effacez ce qui s'y trouve, puis collez le texte. Cliquez sur l'icône Enregistrer (la disquette).
  4. En haut à droite : Déployer → Nouveau déploiement. Cliquez sur la roue dentée et choisissez Application Web.
    « Exécuter en tant que » : Moi. « Qui a accès » : Tout le monde. Puis Déployer.
  5. Google demande d'autoriser l'accès : choisissez votre compte @civipedia.org. S'il affiche « Google n'a pas validé cette application », cliquez sur Paramètres avancés puis Accéder à… (non sécurisé) : c'est votre propre script.
  6. Copiez l'URL de l'application Web (elle se termine par /exec) et envoyez-la à Claude : il l'ajoutera à la page.
  7. Revenez au tableur et rechargez la page : un menu Civipédia apparaît. Choisissez Activer le résumé du lundi et autorisez une dernière fois.

« Tout le monde » permet aux personnes rencontrées d'envoyer une fiche sans compte Google. Elles peuvent seulement ajouter une fiche : personne ne peut lire le tableur par ce guichet. Le texte ne contient ni mot de passe ni donnée.
